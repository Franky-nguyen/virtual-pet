# Evolved (Level 10) Dog — Sprite Sheet Spec

Target: replace the placeholder art in `src/assets/pets/evolved/` with real
64×64px-tile artwork. The renderer already draws evolved tiles at 64px, so
dropping correct files here requires **no code changes**.

## Global rules

- **Format**: PNG, RGBA (transparent background), 8-bit per channel.
- **Tile grid**: every sheet is a **single horizontal row** of N equal-sized
  tiles, each **64×64 px**.
- **Pixel art**: keep hard pixel edges (no anti-aliased/soft edges). The CSS
  already sets `image-rendering: pixelated`.
- **Alignment**: the dog must sit in the **same position and on-screen
  footprint** in every frame so the animation doesn't wobble. Pick one anchor
  (e.g. feet on the bottom of the tile, body centered horizontally) and hold
  it across all frames of a sheet *and* across sheets (idle/walk/hurt/death).
- **Filenames**: lowercase, exactly as listed below, in `src/assets/pets/evolved/`.
- No accessory variants are needed — the evolved dog always uses the base sheet
  (the code ignores accessories once `isEvolved` is true).

## Required sheets

| File                    | Frames | Tile | Sheet size (W×H)      | Notes |
|-------------------------|--------|------|-----------------------|-------|
| `idle.png`              | 8      | 64   | 512 × 64              | Gentle idle loop |
| `walk.png`              | 6      | 64   | 384 × 64              | Walk cycle |
| `attack.png`            | 4      | 64   | 256 × 64              | |
| `death.png`             | 4      | 64   | 256 × 64              | Final frame = dead pose |
| `hurt.png`              | 3      | 64   | 192 × 64              | Slouching / hurt |
| `evolution.png`         | 8      | 64   | 512 × 64              | See note below |
| `evolved_dog_last_frame.png` | 1 | 64 | 64 × 64              | Static settled pose (used as a single-frame fallback / poster) |

### `evolution.png` special case

- 8 tiles wide, but **only the first 7 are animated** (the one-shot evolution
  plays `steps(7)`). The **8th tile is the settled evolved dog** and is never
  stepped through — it must be a clean, stable idle pose.
- Animation reads left → right across the 7 frames.

## Frame counts are authoritative

These counts are hard-coded in `src/types/accessories.ts`
(`EVOLVED_ANIMATION_FRAMES`). If you change the number of frames you must also
update that file, or the animation will desync.

## How to install

1. Draw/save each sheet at the dimensions above into `src/assets/pets/evolved/`.
2. Delete the placeholder `src/assets/pets/evolved64/` folder (generated by
   `generate_evolved_sprites.py`) if you created it.
3. Rebuild / restart. No source changes needed.
